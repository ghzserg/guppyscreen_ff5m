# Фильтрация конфига и отдельная загрузка макросов

База: main d5b8f95 (Icons). Патч не меняет внешние библиотеки и не
включает PNG-декодер или тестовую инфраструктуру.

В `configfile` сохраняются следующие секции целиком:

| Часть | Секции |
| --- | --- |
| config | extruder, input_shaper |
| settings | extruder, firmware_retraction, printer |

Остальные секции внутри config/settings отбрасываются JSON-фильтром до
сохранения в State. Другие поля configfile, включая save_config_pending,
warnings и save_config_pending_items, сохраняются. Остальные объекты
printer_state не фильтруются, включая print_stats и объекты макросов.

При первом открытии вкладки макросов выполняется printer.objects.query
с objects.configfile=["config"]. Ответ разбирается с разрешёнными секциями
gcode_macro. Из них извлекаются имена и параметры; тела G-code в State
не попадают. Построенный интерфейс сохраняется при переключении вкладок.
После reconnect список и запрос обновляются; ответы предыдущего поколения
игнорируются. Если запрос вернул ошибку, повтор возможен при открытии вкладки.

В начале main вызывается mallopt(M_MMAP_THRESHOLD, 128 * 1024). Это фиксирует
порог glibc для mmap вместо его динамического повышения после освобождения
больших блоков. Настройка действует на весь процесс. Она не гарантирует
освобождение каждого большого блока через munmap или снижение RSS.

## Проверка на принтере

1. Сохранить предыдущий бинарник для отката. Применить патч к d5b8f95
   или проверить применимость к более новой основной ветке.
2. Собрать приложение обычным способом. Существующий патч libhv 0005
   сохранить: данный этап его не добавляет и не отменяет.
3. Проверить текущий файл печати, zmod_color, параметры экструдера,
   ретрактов, input shaper и обоих вариантов ограничения ускорения.
4. Открыть макросы, выполнить безопасный макрос с параметрами, переключить
   вкладки. После reconnect проверить обновление списка и скрытые макросы.
5. При одинаковом сценарии экранов сравнить лог /proc с lasrt. Отдельно
   измерить до и после первого открытия макросов. Для проверки длительной
   стабильности повторить reconnect и открытия вкладки несколько раз.

Автоматические проверки выполняются локально, вне репозитория.

## Локальная проверка этапа

Собрано host-приложение с актуальными исходниками и индексированными
иконками. Все 16 проверок прошли, включая фильтрацию реального configfile.json,
сохранение параметров макросов, отдельную загрузку списка, повторный запрос
после ошибки, reconnect, живые обновления после большого сообщения и
сохранение используемых панелями значений в State.

После фильтрации реального ответа сериализованный JSON занимает 2436 байт.
Это не оценка RSS. Проверки не добавлены в репозиторий.
Вызов mallopt отдельно скомпилирован и выполнен на host glibc. Полная
целевая сборка и замер влияния аллокатора выполняются на принтере;
оборудование и заголовок tslib.h в host-окружении отсутствуют.
